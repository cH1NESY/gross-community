# 🚀 Быстрый старт отправки SMS уведомлений

## ✅ Что уже готово:

1. ✅ RabbitMQ настроен и запущен
2. ✅ Job для отправки SMS создан и настроен на SMS.ru API
3. ✅ API ключ добавлен в .env
4. ✅ Номер телефона настроен

## 🎯 Что нужно сделать сейчас:

### 1. Перезагрузить конфигурацию Laravel

```bash
cd backend
docker exec php-fpm-gross php artisan config:clear
docker exec php-fpm-gross php artisan cache:clear
```

### 2. Запустить воркер очередей

**Важно:** Без запущенного воркера SMS не будут отправляться!

```bash
cd backend
./start-queue-worker-daemon.sh
```

Проверьте, что воркер запущен:
```bash
docker exec php-fpm-gross ps aux | grep queue:work
```

Вы должны увидеть процесс `queue:work rabbitmq`.

### 3. Протестировать отправку SMS

```bash
cd backend
./test-sms-direct.sh
```

Или через форму на сайте:
1. Откройте сайт
2. Заполните форму регистрации
3. Нажмите "Получить консультацию"
4. Проверьте SMS на телефоне 89243513155

### 4. Проверить логи

```bash
# Логи отправки SMS
docker exec php-fpm-gross tail -f storage/logs/laravel.log | grep -i sms

# Или все логи
docker exec php-fpm-gross tail -f storage/logs/laravel.log
```

## 📱 Ожидаемый результат

После отправки заявки на консультацию на номер **89243513155** должно прийти SMS:

```
Новая заявка на консультацию!
Имя: [Имя пользователя]
Телефон: [Телефон пользователя]
Email: [Email пользователя]
Время: [Дата и время]
```

## ⚠️ Важные моменты

1. **Воркер должен быть запущен постоянно** - без него задачи не обрабатываются
2. **Проверьте баланс на SMS.ru** - должен быть минимум 5 рублей
3. **Номер телефона в .env** должен быть в формате: `89243513155` (без + и пробелов)
4. **API ключ** должен быть правильным (API_ID из личного кабинета SMS.ru)
