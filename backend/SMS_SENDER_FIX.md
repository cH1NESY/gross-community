# ⚠️ Проблема с отправкой SMS

## 🔍 Найденная проблема:

SMS.ru возвращает ошибку **код 221**: *"Для работы с нашим сервисом, необходимо создать буквенного отправителя"*

Это означает, что в вашем аккаунте SMS.ru нужно создать буквенного отправителя (sender name).

## ✅ Решение:

### Шаг 1: Создайте буквенного отправителя в SMS.ru

1. Войдите в личный кабинет SMS.ru: https://sms.ru/?panel=senders
2. Создайте нового буквенного отправителя (например: `GROSSCOMMUNITY` или `GROSS`)
3. Дождитесь модерации (обычно несколько часов)

### Шаг 2: Добавьте имя отправителя в .env

После создания отправителя добавьте в `.env`:

```env
SMS_FROM=GROSSCOMMUNITY
```

(Замените `GROSSCOMMUNITY` на имя вашего отправителя)

### Шаг 3: Перезапустите воркер

```bash
cd backend
# Остановите текущий воркер (Ctrl+C)
# Запустите снова
./start-queue-worker.sh
```

## 🔧 Что было исправлено в коде:

1. ✅ Добавлена обработка ошибок внутри ответа SMS.ru
2. ✅ Добавлена поддержка параметра `from` (буквенный отправитель)
3. ✅ Улучшено логирование ответов API

## 📊 Проверка:

После создания отправителя и добавления `SMS_FROM`, попробуйте снова отправить заявку на консультацию. SMS должно прийти на номер **89243513155**.

## 💡 Альтернатива (для тестирования):

Если нужно протестировать систему без создания отправителя, можно временно закомментировать проверку ошибок, но SMS.ru все равно не отправит SMS без одобренного отправителя.
