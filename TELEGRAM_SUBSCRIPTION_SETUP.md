# Настройка проверки подписки в Telegram

## Что реализовано:

1. ✅ Страница проверки подписки (`/check-subscription`)
2. ✅ API endpoint для проверки через Telegram Bot API
3. ✅ Интеграция в дизайн сайта (градиенты, розовые акценты)
4. ✅ Ссылка в Header (десктоп и мобильная версии)

## Настройка на сервере:

### 1. Создайте Telegram бота:

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)
4. Сохраните username бота (например: `grosscbot`) — он понадобится для сообщений пользователям

### 2. Добавьте бота в группу:

1. Создайте или откройте вашу Telegram группу
2. Добавьте бота в группу как администратора
3. Дайте боту права на просмотр участников

### 3. Получите ID группы:

**Вариант 1: Через бота @userinfobot (рекомендуется)**
1. Добавьте `@userinfobot` в группу (можно добавить временно)
2. Бот автоматически покажет ID группы в сообщении
3. ID группы будет отрицательным числом (например: `-1001234567890`)
4. Скопируйте этот ID (только число, без пробелов)

**Вариант 2: Через getUpdates API**
1. Отправьте любое сообщение в группу (или добавьте бота)
2. Выполните запрос:
```bash
curl "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates"
```
3. Найдите `chat.id` в ответе (отрицательное число для групп, например: `-1001234567890`)
4. Скопируйте этот ID

**Вариант 3: Для группы с пригласительной ссылкой (https://t.me/+...)**
1. Добавьте бота в группу как администратора
2. Отправьте любое сообщение в группу или добавьте бота
3. Используйте `@userinfobot` или метод `getUpdates` (см. варианты 1 и 2 выше)
4. ID группы будет отображаться как отрицательное число

**Важно:** ID группы всегда отрицательное число для групп (например: `-1001234567890`). Для супергрупп ID начинается с `-100`.

### 4. Добавьте переменные в .env:

```bash
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=-1001234567890
TELEGRAM_BOT_USERNAME=grosscbot
TELEGRAM_GROUP_LINK=https://t.me/+tTW-bBfMvyI0ZTE1
```

**Где взять TELEGRAM_CHAT_ID:**
- Если у вас группа с пригласительной ссылкой (например: `https://t.me/+tTW-bBfMvyI0ZTE1`), добавьте бота `@userinfobot` в группу
- Бот автоматически покажет ID группы (отрицательное число, например: `-1001234567890`)
- Альтернативно, используйте метод `getUpdates` через API (см. раздел "Получите ID группы" выше)

### 5. Перезапустите контейнеры:

```bash
cd ~/gross-community/backend
docker-compose restart php-fpm
```

## Проверка работы:

1. Откройте страницу: `http://5.129.248.5/#/check-subscription`
2. Введите Telegram username (без @)
3. Нажмите "Проверить подписку"

## API Endpoint:

- **URL**: `POST /api/check-subscription`
- **Body**: `{ "telegram_username": "username" }`
- **Response**: 
  ```json
  {
    "success": true,
    "subscribed": true/false,
    "message": "Сообщение",
    "status": "member" // или "left", "kicked", etc.
  }
  ```

## Важно:

- Telegram username должен быть без символа `@`
- Профиль пользователя должен быть публичным (Settings → Privacy → Profile Photos → Everybody)
- Бот должен быть администратором группы для проверки участников
- ID группы всегда отрицательное число для групп
- Для каналов ID может быть положительным (например: `@channelname`)
